# Privacy statement

Aegis Note Locker encrypts note content locally. It does not require an account, collect analytics, call an AI service, upload vault content, or send passwords anywhere. Optional billing sync and checkout use TutivSoft Constance and send only the app ID, a random install ID, billing email for checkout, and one-use event IDs. Passwords, decrypted content, encryption keys, note paths, encrypted envelopes, and protected properties are not placed in notices, logs, clipboard data, plugin settings, or network requests.

The plugin stores its session timeout and backup-folder preference in Obsidian plugin data. Encrypted note envelopes and user-requested encrypted exports are stored in the vault. The export includes a source path label so the user can identify it; the note content itself is encrypted.

Install only plugin builds you trust. A compromised device or another plugin with access to the unlocked editor can still read plaintext; client-side encryption does not change that boundary.
