# Aegis Note Locker

Version: 3.3.35

Protect note bodies and selected frontmatter values with local authenticated encryption.

## Pricing and usage

The verified active one-time Paddle offers are:

| Price | Included native units |
| ---: | ---: |
| $1 USD | 100 credits |
| $10 USD | 1,000 credits |

Aegis uses credits for paid protected-note operations; current costs are quoted by Constance before a write. The plugin loads current price and product details from Constance/Paddle and displays the confirmed amount and native units before checkout. Prices and availability shown in Obsidian are current at purchase time.

## Installation

In Obsidian, open **Settings → Community plugins → Browse**, search for **Aegis Note Locker**, install it, and enable it.
